# Anime Buddies — Privacy Policy
 
**Effective Date:** September 15, 2026
 
This Privacy Policy describes how the Anime Buddies mobile application ("Application"), provided by Brian S Rosales ("Service Provider," "we," "us," or "our"), handles information when you use it. This Application is provided as a Freemium service, "AS IS."
 
---
 
## 1. Information We Collect
 
The Application collects limited technical and usage data for analytics purposes, in order to understand how the Application is used and to improve its features and performance. This may include:
 
- General usage data, such as which features or screens are used and how often
- Device and operating system information (e.g., OS version, device type)
- Approximate, non-precise technical metadata (such as general app performance data)
**We do not tie this data to your individual identity.** The Application does not collect or store information in a way that identifies a specific user. Analytics data is collected and used only in aggregated or de-identified form, and is not linked back to any individual person or device profile.
 
The Application does not collect precise location information. But we do ask for it if you want to see weather on your widget that is all.

## 2. How We Use Information
 
Aggregated, non-identifying analytics data is used solely to:
 
- Understand general usage patterns and trends
- Identify and fix bugs or performance issues
- Improve and develop new features
We do not use this data to build individual user profiles, track individuals across sessions, or personally target users with advertising based on their behavior.

## 3. Third-Party Analytics Services
 
The Application may use third-party analytics tools to help collect and process aggregated usage data described above. These providers only receive anonymized or aggregated data and do not receive information that identifies you individually.
 
We may also disclose information if:
 
- required by law, such as to comply with a subpoena or similar legal process; or
- necessary in good faith to protect our rights, the safety of users or others, investigate fraud, or respond to a lawful government request.

## 4. Data Retention
 
Since analytics data is collected in aggregated, non-identifying form, it is not tied to a specific user account or device and is retained only as long as needed to support the analytics purposes described above.
 
If the Application ever collects information you directly provide (for example, if you contact us), we retain that information only as long as necessary to respond to you or as required by law.
